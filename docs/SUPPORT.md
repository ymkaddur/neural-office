# Apoyar Neural Office

El software es gratuito y open source. Las aportaciones ayudan a mantener desarrollo, pruebas y distribución; todas las funciones disponibles son iguales para quienes aportan y quienes no.

| Plataforma | Estado |
|---|---|
| [Patreon](https://www.patreon.com/Neural_office) | Página de apoyo publicada |
| GitHub Sponsors | Activación de cobros pendiente |

Patreon ofrece importes base de **1 €, 3 €, 5 € y 10 € al mes**. No incluyen funciones, contenido ni soporte exclusivos, prioridad de respuesta ni trabajo personalizado. La plataforma muestra el total aplicable antes de confirmar.

El botón Sponsor enlaza a Patreon. Los niveles de GitHub Sponsors se definirán al activarlo; no se promete equivalencia entre divisas. La configuración de cobros permanece fuera del trabajo de desarrollo.

También puedes ayudar con una reproducción de un fallo, una prueba de uso o una mejora de documentación. El equipo, los modelos y cualquier servicio externo mantienen sus propios requisitos y licencias.
